# FastAPI Docker Demo

A simple FastAPI application containerized using Docker.

## Technologies Used

- Python
- FastAPI
- Uvicorn
- Docker

## Run with Docker

Pull the Docker image:

docker pull gayudangi/fastapi-app:v1

Run the container:

docker run -p 8000:8000 gayudangi/fastapi-app:v1

Open in browser:

http://localhost:8000
